## 4. 問題回答

### 問題一：測試一中，整理後的桌遊串列有 4 筆資料，為什麼桌遊費用應以 3 人計算？直接把字串拆成 list，和再轉成 set，各自保留了什麼、失去了什麼？

桌遊整理後的串列為 `['amy', 'ben', 'amy', 'cora']`，共有 4 筆紀錄，但其中 `'amy'` 出現了兩次，代表同一位參加者在同一場活動重複報名。依活動規則，同一人在同一場活動只算一位參加者且只收一次費用，因此實際去重後的桌遊人數為 3 人（`amy`、`ben`、`cora`），費用應以 3 人計算（`3 × 120 = 360.00 元`）。

- **直接把字串拆成 `list`**：
  - **保留了什麼**：保留了原始填報的先後順序，也保留了重複出現的次數與紀錄，適合用來觀察原始報名狀況。
  - **失去了什麼**：沒有自動去重，若直接用長度計算人數或收費，會把重複報名誤算成多位參加者；同時也不支援直接做集合的交集、聯集與差集比較。
- **再轉成 `set`**：
  - **保留了什麼**：保留了不重複的參加者身分集合，方便快速計算不重複人數並比較兩場活動的名單重疊與差異。
  - **失去了什麼**：失去了原本的排列順序與重複報名次數，且元素沒有固定索引位置，若要依字母順序顯示或做切片操作，還需要另外轉回排序後的 `list`。

### 問題二：測試三中，兩場活動只有 3 位不同的人，為什麼是 6 人次、總應收仍是 600 元？請用集合關係與算式說明。

在測試三中，桌遊去重集合為 $B = \{\text{amy}, \text{ben}, \text{cora}\}$（$|B| = 3$），電影去重集合為 $M = \{\text{amy}, \text{ben}, \text{cora}\}$（$|M| = 3$）。兩場去重後的名單完全相同，因此：
- 交集（共同參加者）：$B \cap M = \{\text{amy}, \text{ben}, \text{cora}\}$，$ |B \cap M| = 3 $
- 聯集（全部不重複參加者）：$B \cup M = \{\text{amy}, \text{ben}, \text{cora}\}$，$ |B \cup M| = 3 $

「總不重複人數」看的是至少參加一場活動的不同個人數，所以是聯集大小 $3$ 人；而「報名人次」看的是兩場活動各自去重後的人數總和，因為這 3 人每一場都各報了一次，每人各產生 2 人次，因此是：
$$\text{報名人次} = |B| + |M| = 3 + 3 = 6\text{（人次）}$$

至於費用是依照各場活動去重後的人數分別乘上該場單價計算，不會因為兩場名單重疊而打折或少算：
$$\text{桌遊應收} = 3 \times 120 = 360\text{（元）}$$
$$\text{電影應收} = 3 \times 80 = 240\text{（元）}$$
$$\text{總應收} = 360 + 240 = 600\text{（元）}$$
